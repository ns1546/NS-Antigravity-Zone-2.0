## ⚡ 1-Click System Deployment & Restore

To deploy or restore the entire NS Antigravity Zone 2.0 system onto any Windows machine:

```powershell
# 1. Clone this repository
git clone https://github.com/ns1546/NS-Antigravity-Zone-2.0.git
cd NS-Antigravity-Zone-2.0

# 2. Run the automated deployment engine
powershell -ExecutionPolicy Bypass -File .\install-antigravity.ps1
```

The script automatically sets up:
- ✅ **116 Skills** deployed to `C:\Users\<User>\.gemini\config\skills\`
- ✅ **30 Custom Specialist Agents** deployed to `C:\Users\<User>\.gemini\config\agents\`
- ✅ **3 Core Rules** deployed to `C:\Users\<User>\.gemini\config\rules\`
- ✅ **9 Production Plugins** registered in `C:\Users\<User>\.gemini\config\plugins\`
- ✅ **Builtin AGY Skills & Native MCP Tool Schemas** bound to `C:\Users\<User>\.gemini\antigravity-ide\`
- ✅ **Master Directives** injected into `AGENTS.md` and `GEMINI.md`.
