## ⚡ 1-Click Installation & System Restore

To restore or install this complete Antigravity ecosystem on any Windows machine:

```powershell
# Open PowerShell as Administrator or regular user and run:
git clone https://github.com/ns1546/NS-Antigravity-Zone-2.0.git
cd NS-Antigravity-Zone-2.0
powershell -ExecutionPolicy Bypass -File .\install-antigravity.ps1
```

The script automatically:
1. Deploys all 19 agents into `C:\Users\<User>\.gemini\config\agents`
2. Deploys all 38 skills into `C:\Users\<User>\.gemini\config\skills`
3. Installs and registers all 11 plugins into `C:\Users\<User>\.gemini\config\plugins`
4. Deploys engineering rules into `C:\Users\<User>\.gemini\config\rules`
5. Restores builtin skills into `C:\Users\<User>\.gemini\antigravity-ide\builtin`
6. Binds all MCP schemas into `C:\Users\<User>\.gemini\antigravity-ide\mcp`
7. Injects `AGENTS.md` and `GEMINI.md` master directives.
